# 🧠 Criando um Projeto Java com IntelliJ IDEA

## Passo a passo

1. Abra o IntelliJ IDEA
2. Clique em **New Project**
3. Selecione **Spring Boot** (ou **Java** para projeto simples) no menu lateral
4. Preencha os campos de metadados do projeto:
   - **Name** → nome do projeto
   - **Location** → onde o projeto será salvo
   - **Language** → Java, Kotlin ou Groovy
   - **Build system** → Maven ou Gradle
   - **JDK** → versão do Java instalada
   - **Java** → versão da linguagem
   - **Group / Artifact / Package name**
5. Se estiver criando um projeto Spring Boot, escolha a versão do **Spring Boot**
6. Selecione as **Dependencies** desejadas (Spring Web, Lombok, DevTools etc.)
7. Clique em **Create** / **Finish**
8. O IntelliJ vai baixar as dependências e montar a estrutura do projeto automaticamente

> 💡 O IntelliJ Ultimate tem integração nativa com o Spring Initializr, então o assistente de criação é praticamente idêntico ao do site.
